# Contributing to Everywhere Harness

Thank you for your interest in contributing to Everywhere Harness!

We welcome contributions from the community, whether it's fixing bugs, adding new features, improving documentation, or creating plugins.

## How to Contribute

1. **Reporting Issues**:
   - Check existing issues in [GitHub Issues](https://github.com/everson-junior/everywhere-harness/issues) to avoid duplicates.
   - Provide clear reproduction steps, environment details (OS, Node version), and relevant logs.

2. **Pull Requests**:
   - Fork the repository and create your feature branch: `git checkout -b feature/my-new-feature`.
   - Ensure your code passes standard checks and tests.
   - Commit your changes with clear, descriptive commit messages.
   - Open a pull request against the `master` branch.

3. **Developing Locally**:
   ```bash
   pnpm install
   pnpm run build
   pnpm ewh web
   ```

Thank you for helping make Everywhere Harness better!
